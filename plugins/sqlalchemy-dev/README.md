# sqlalchemy-dev

SQLAlchemy dev plugin for Agents Store. Model definition patterns, relationship mapping, query optimization, Alembic migrations, and troubleshooting for developers building with SQLAlchemy 2.0+.

## Skills

| Skill | Description |
|-------|-------------|
| `setup` | Verify SQLAlchemy configuration and database connection |
| `model-patterns` | Model definitions, relationships, column types, constraints, mixins |
| `query-patterns` | Queries, filtering, joins, aggregations, eager loading, pagination |
| `api-reference` | Core SQLAlchemy API (column types, session methods, relationship options) |
| `cli-recipes` | Alembic / Flask-Migrate migration commands |
| `troubleshoot` | Common SQLAlchemy errors and diagnostic steps |

## Agent

**sqlalchemy-developer** — SQLAlchemy development specialist for defining models, writing queries, managing migrations, and debugging database issues.

## Installation

Install via Agents Store or add manually to your Claude Code plugins.

## Prerequisites

- Python 3.8+
- SQLAlchemy 2.0+ or Flask-SQLAlchemy 3.x
