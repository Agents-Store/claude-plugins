# nextjs-dev

Next.js development plugin for the Agents Store marketplace. Knowledge base for building modern Next.js applications with App Router, Server/Client Components, data fetching, caching, and performance optimization.

## Type

Technology (Level 1) — knowledge-only, no MCP server bundled.

## Skills

| Skill | Description |
|-------|-------------|
| `setup` | Verify Next.js project environment and readiness |
| `app-router-patterns` | App Router file conventions, routing, layouts, metadata, middleware |
| `server-client-components` | Server vs Client Component patterns, boundaries, composition |
| `data-fetching` | Data fetching, Server Actions, caching, ISR, streaming |
| `mcp-tools` | Next.js DevTools MCP server reference (`next-devtools-mcp`) |
| `api-reference` | Framework API quick reference (functions, config, types) |
| `cli-recipes` | CLI commands, scripts, Docker deployment |
| `performance-optimization` | Image/font optimization, bundle analysis, Core Web Vitals |
| `troubleshoot` | Common errors, hydration issues, debugging |
| `examples` | End-to-end scenario walkthroughs (dashboard, e-commerce) |

## Agent

**nextjs-developer** — Next.js development specialist for building pages, fetching data, debugging issues, and optimizing performance.

## Prerequisites

- A Next.js project (14+ for App Router, 16+ for Cache Components and built-in MCP)
- For MCP integration: install `next-devtools-mcp` in your project

## Installation

Install as a Claude Code plugin from the Agents Store marketplace.
