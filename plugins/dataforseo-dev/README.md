# dataforseo-dev

DataForSEO data for SEO work — keywords, SERP, backlinks, on-page, AI visibility — through the v3 MCP server. Not a general web-search tool: for web search and scraping use `web-search-dev`.

This is the **data layer** for SEO work. `seo-dev` teaches code-level SEO implementation; `dataforseo-dev` pulls real search data so you can decide *what* to optimize.

## What Changed in 2.0.0

The plugin now targets `dataforseo-mcp-server` **v3**, which replaces the 76 per-endpoint tools of v2 with **four tools**. The old tool names (`dataforseo_labs_google_keyword_ideas`, `backlinks_summary`, `serp_organic_live_advanced`, and the rest) no longer exist. Every endpoint is now an `api_request` with a REST path, and the documentation is searchable from the same server. The plugin pins `dataforseo-mcp-server@3` so a later major version cannot change the tool surface silently.

| Tool | Purpose | Cost |
|------|---------|------|
| `docs_list_sections` | The 13 documentation sections | free |
| `docs_index` | Endpoints of a section | free |
| `docs_search` | One endpoint's documentation: fields, limits, Pricing link | free, cached 24 hours |
| `api_request` | Authenticated request to any endpoint | **paid** |

## Commands

| Command | Description |
|---------|-------------|
| `/dataforseo-dev:keyword-research <topic>` | Run keyword research for a topic or domain |
| `/dataforseo-dev:site-audit <url>` | Run an on-page SEO audit for a URL |
| `/dataforseo-dev:competitor-analysis <domain>` | Compare a domain against competitors |

The commands list `api_request` and `docs_search` as allowed tools, so Claude Code does not prompt for them. Each command therefore shows its plan and asks for a budget before the first paid call.

## Agent

**seo-data-analyst** — SEO data analysis specialist. Reads the docs first, agrees a budget, then chains `api_request` calls for a complete analysis.

## Prerequisites

- **DataForSEO account** — Sign up at [dataforseo.com](https://dataforseo.com)
- **Node.js 22 or newer** — Required by the v3 MCP server
- **API credentials** — the API login and the **API password** from [app.dataforseo.com/api-access](https://app.dataforseo.com/api-access). The API password is generated by DataForSEO; it is not your account password.
- **Environment variables:**
  - `DATAFORSEO_USERNAME` — the API login. The plugin's `.mcp.json` reads this name; the server accepts it as an alias of `DATAFORSEO_LOGIN`, the name its own documentation uses
  - `DATAFORSEO_PASSWORD` — the API password

## MCP Server

The plugin's `.mcp.json` runs the official [dataforseo-mcp-server](https://www.npmjs.com/package/dataforseo-mcp-server) at major version 3 through npx. Through `api_request` it reaches all 13 documentation sections:

- **SERP** — Google, Bing and YouTube results, AI Mode, Maps, News, Images, autocomplete
- **AI Optimization** — LLM Mentions, ChatGPT and Gemini LLM Scraper, LLM Responses from ChatGPT, Claude, Gemini and Perplexity, AI keyword volume
- **Keywords Data** — Google Ads volume, Google Trends, DataForSEO Trends
- **Domain Analytics** — Technology detection, WHOIS
- **DataForSEO Labs** — Keyword research and domain analysis
- **OnPage** — Lighthouse audits, page analysis, content parsing, site crawl
- **Backlinks** — Link profiles, referring domains, spam scores
- **Content Analysis** — Sentiment, citations, phrase trends
- **Merchant** — Amazon and Google Shopping data
- **App Data** — Google Play and App Store listings
- **Business Data** — Business listings, Google business profiles, Tripadvisor, Trustpilot
- **Databases** and **Appendix** — bulk data products, status codes, sandbox, account data

By default the server asks DataForSEO for the cropped `.ai` form of each response (smaller, no `cost` field, `limit` and `depth` default to 10); pass `noAiMode: true` for the full response. Responses can also be trimmed per endpoint with the server's field-config option; see the `mcp-patterns` skill.

## Cost Model

DataForSEO bills per request, at a price that differs by endpoint. The documentation tools are free; every `api_request` to a data endpoint is paid. The `cost-awareness` skill is the gate: the plugin shows a plan and gets an agreed budget before its first paid call. Monitor usage at [app.dataforseo.com](https://app.dataforseo.com).
